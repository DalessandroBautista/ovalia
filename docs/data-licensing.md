# Procedencia y licencias de datos

Todo proveedor debe registrarse con URL, atribución, capacidades, permiso de
automatización y fecha de verificación en `external_sources`. No se deben publicar
datos, textos, escudos o fotografías fuera del alcance de la licencia correspondiente.

Antes del lanzamiento deben verificarse por proveedor:

- permiso para consultar, almacenar y redistribuir resultados, fixtures y posiciones;
- términos y límites de uso de Highlightly, URBA y cualquier fuente futura;
- licencia o autorización de cada escudo almacenado en `apps/web/public/teams`;
- atribución visible cuando la fuente la exige;
- mecanismo para retirar o corregir contenido ante una reclamación.

Este documento no sustituye una revisión legal ni las condiciones de cada proveedor.
